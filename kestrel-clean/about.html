The Movie Night Incident

terminal

It was a cold Friday evening. Jellyfin buffered indefinitely on the living room screen while local NFS mounts hung dead in their tracks. What should have taken thirty seconds of diagnostic work spiraled into a two-hour battle against bloated enterprise monitoring daemons.

The incident response required spinning up an orchestration stack that swallowed half the system memory just to establish that an unmanaged 8-port gigabit switch in the garage attic had lost its power brick. The software designed to monitor the home was hungrier than the services it was supposed to oversee.

warning ERROR: Monitoring agent evicted by OOM-killer while pinging gateway 192.168.1.1.

That night, the core thesis of Kestrel was drafted on a scrap of paper: homelab operators shouldn't need a Kubernetes cluster to keep tabs on three Raspberry Pis, a refurbished OptiPlex, and their family storage array.

We set out to write an unyielding, passive network monitor in compiled Go. It had to execute directly on raw network sockets, bind directly to eBPF filters for zero-overhead packet telemetry, and store years of compressed time-series points locally inside a lean, WAL-mode SQLite database.

No subscription tiers. No OAuth handshakes through external cloud identity providers. No tracking beacons disguised as "product analytics." Just raw, uninterrupted sovereignty over your personal computing estate.

Engineered For Efficiency

Technical Architecture & Stack

terminal

Backend Engine

Go 1.22+

Compiled static single binary with zero external shared library dependencies. Utilizes eBPF tracing probes for kernel-level network socket auditing and raw socket ICMP generation without invoking shell subprocesses.

eBPF Ring Buffers Raw ICMP Sockets Zero-Alloc Goroutines Static ELF Binary
database

Local Persistence

WAL + DuckDB

State telemetry is handled through an embedded SQLite database configured with Write-Ahead Logging for high-throughput concurrent reads. High-resolution time-series rollups are systematically compressed using vectorized DuckDB storage blocks.

Embedded SQLite WAL Concurrency ZSTD Compression Local File Only
